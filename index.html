        📝 怎麼拿免費金鑰？（約 3 分鐘）
        1. 打開 aistudio.google.com/apikey，用你的 Google 帳號登入。
        2. 第一次會跳出使用條款，勾選同意後繼續。
        3. 按「Create API key（建立 API 金鑰）」；如果要你選專案，選預設的或新建一個就好。
        4. 按複製，拿到一串 AIza 開頭的英文數字。
        5. 回到這裡貼上 → 按「儲存」→ 再按「測試」，看到 ✅ 就完成了。

        免費版有每分鐘／每天次數上限，用完會自動改用站內回答，稍等就恢復。免費版的提問 Google 可能拿去改善模型，不要輸入個人隱私或病歷。金鑰外流的話，回同一頁把它刪掉再建一把新的。
